# ControllerBridge icon

Original project branding, generated with the built-in image-generation tool on
2026-10-14. No manufacturer logos or third-party icon art were used.

Final prompt: production Windows app icon; bold white simplified gamepad with
a bridge arch/connected span; deep teal rounded-square tile (accent #26A69A),
one mint bridge accent; strong silhouette readable at 16/32 pixels; transparent
outside the tile; no text, manufacturer logos, watermark or mockup.

`ControllerBridge-source.png` retains the generated RGBA original. The 256 px
PNG and multi-resolution ICO are mechanically downsampled with Pillow LANCZOS,
retaining alpha. ICO sizes: 16, 20, 24, 32, 40, 48, 64, 128, 256 px.

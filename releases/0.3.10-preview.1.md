ControllerBridge Manager 0.3.10-preview.1

修复高缩放显示器上文字、图标发糊，以及鼠标滚轮在大部分区域无效的问题。旧版程序缺少 DPI 感知声明；在本次 175% 缩放环境中，Windows 将它识别为 96 DPI 程序并放大显示。新版在创建窗口前启用 PerMonitorV2，让 WinUI 按显示器实际 DPI 渲染和处理输入。

初始窗口和“已在运行”提示窗口按逻辑尺寸换算为物理像素，并限制在显示器工作区内。保留 Fluent 卡片主页、输入测试、映射、更新及所有接收器功能，保留已有滚轮和触控逻辑。

验证：

- 175% 缩放下，运行时检查由 DPI unaware / 96 DPI 变为 PerMonitorV2 / 168 DPI，XAML 缩放为 1.75。
- 原版在主页卡片、文字上注入滚轮后滚动条仍为 0；DPI 修复版同类操作使页面实际偏移由 0 变为 476。用户在离线测试窗口现场确认“清晰，滚轮也正常”。
- 新增启动 DPI、XAML 缩放与窗口物理尺寸一致性回归；现有界面回归按逻辑窗口尺寸执行，覆盖多种窗口宽度、明暗主题、创建向导、映射和嵌套列表滚动。
- 增加 `--wheel-smoke <输出目录>` 离线交互验证入口，记录真实滚轮和滚动偏移，不发现或连接硬件。可用 `-p:UiSmokeHost=true` 构建独立测试进程，避免与已安装管理器混淆。

包含 0.3.9 的 BL616 USB OTA 速度修复。四平台固件模块及锁定清单保持不变；本版只更新管理器，不需要重新刷写接收器。

在 Manager 更新中启用“包含预发布版本”后检查更新，或下载安装包/便携包。完整退出旧版并启动新版后生效。

ControllerBridge Manager 0.3.7-preview.1

本预览版把 SF32 Nano、Pico 2 W 和 ESP32-S3 的实际固件与管理协议合入同一管理器，保留已发布 BL616 0.2.3-preview.1 的原始模块和签名 OTA 镜像。

| 平台 | 模块版本 | 物理无线输入 | USB 输出 |
| --- | --- | --- | --- |
| BL616 | 0.2.3-preview.1，原包不变 | DualSense/Edge Classic、NS2Pro BLE | DualSense、Edge、XInput、NS2Pro |
| SF32LB52 Nano n16r16 | 0.8.0-preview.1 | DualSense/Edge Classic、NS2Pro BLE | 同上 |
| Pico 2 W | 0.2.0-preview.1 | DualSense/Edge Classic、NS2Pro BLE | 同上 |
| ESP32-S3 N4/N8/N8R2/N8R8/N16R8/ESP32SUPERMINI | 0.2.0-preview.1 | NS2Pro BLE | 同上 |

管理器变化：

- 物理输入报告率来自固件的有效源帧计数和设备时间。USB 重发和界面轮询不计入报告率；重复、断开、过期、重连及计数回绕均有处理。
- XInput、串口和 ESP32-S3 管理接口通过实际输入快照驱动现有控制器图示；按键、摇杆、扳机和体感按物理来源解码，电量未知时保持未知。
- SF32 使用六组输入×输出映射；Sony 与 Edge USB 输出共享 Sony 路由。Pico、ESP32 使用固件实际支持的物理输入映射维度，包含扩展键。
- 四平台固件更新与创建流程接通实际镜像。SF32 使用固定版本 sftool；ESP32 使用固定哈希 esptool，检查芯片与 Flash 容量后写入并回读校验；Pico 识别 RP2350 BOOTSEL 启动盘并逐块校验 UF2；BL616 保留签名 USB OTA 与 ROM 恢复。
- USB 身份切换期间保留目标身份，避免旧状态覆盖。ESP32 恢复默认设置后确认复位结果并按 Nintendo 身份重新连接；停止震动保留原来的反馈开关配置，音频未知状态和调节范围按实际固件显示。
- 模块、刷写工具、便携包内所有文件均有大小/哈希检查。应用与安装器版本保持一致，更新源无需 GitHub 登录。

安装：下载 `ControllerBridge-Setup-0.3.7-win-x64.exe`，或使用便携 ZIP。旧版 Manager 中启用“包含预发布版本”即可检查此更新。安装应用不会刷写接收器；按实际板型安装相应固件。已接在电脑上的 RP2350 串口调试桥不是 Pico 接收器，请勿选错设备。

验证记录和版本锁随包提供。固件均为目标 SDK 构建产生的实际镜像；离线回归覆盖协议分片、物理遥测、映射、回连状态机、包完整性、刷写前检查和界面。没有对这些新镜像执行实机刷写、无线配对/唤醒、四身份重枚举、音频或体感方向验收。

已知范围：ESP32-S3 仅有 BLE 物理输入，不能连接 DualSense/Edge；这不限制 USB 输出。Pico 旧 bootstrap 版仅保存地址的 NS2 记录需要重新执行一次配对以建立密钥；正式构建默认 150 MHz。未知 NS2 电量不伪造。跨控制器专属效果（例如自适应扳机）不等于原生效果；各固件发行说明保留具体限制。XInput 不包含 Xbox 主机认证。完整实机验收步骤见便携包 `RELEASE-TESTING.md`。

安装器和便携包未做代码签名。本机已有 Manager 安装，因此没有覆盖它执行安装/卸载测试；已对发布包进行离线验证。

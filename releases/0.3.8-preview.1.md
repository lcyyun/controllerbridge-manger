ControllerBridge Manager 0.3.8-preview.1

创建接收器时，设备页现在只显示一个 ESP32-S3。下一页再选择 N4、N8、N8R2、N8R8、N16R8 或 ESP32SUPERMINI，每张卡片显示 Flash / PSRAM 容量和对应固件版本。

- 新选择必须明确指定实际型号；USB 身份和只有一个型号的模块都不会自动猜测内存配置。
- 已保存的具体型号以及返回/前进操作会保留选择。模块更新移除该型号或固件时，清除旧目标并返回型号选择页。
- 烧录忙状态会锁定目标；模块安装和重载不能替换正在使用的板型或固件。

这是共用 Manager 的界面更新。四个平台沿用 0.3.7-preview.1 内的同一批固件模块，版本和 SHA-256 均不变：

| 平台 | 模块版本 |
| --- | --- |
| BL616 | 0.2.3-preview.1，原始签名模块 |
| SF32LB52 Nano n16r16 | 0.8.0-preview.1 |
| Pico 2 W | 0.2.0-preview.1 |
| ESP32-S3 六板型 | 0.2.0-preview.1 |

下载 `ControllerBridge-Setup-0.3.8-win-x64.exe` 或便携 ZIP。旧版 Manager 启用“包含预发布版本”后也可检查更新。更新 Manager 不会刷写接收器。

发布验证覆盖核心回归、实际四平台模块和镜像、完整 shell/wizard 离线流程、ESP32 六型号选择/恢复/模块减少/忙状态，以及宽窄屏布局。发布资产另行核对大小和 SHA-256，并检查旧版 Manager 的公开升级下载。

本次没有固件变更，也未新增实机刷写、配对/唤醒、USB 身份兼容性或音频/震动验收。此前各固件的限制继续适用，完整清单见包内 `RELEASE-TESTING.md`。安装器未做代码签名；本机已有 Manager 安装，因此保留原安装，没有执行覆盖安装/卸载测试。

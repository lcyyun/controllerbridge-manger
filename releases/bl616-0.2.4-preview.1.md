# BL616 0.2.4-preview.1

修正 NS2Pro 的独立配对和关机后唤醒回连路径。这是等待硬件复测的测试固件。

- 收到 NS2Pro 的物理配对广播后，执行完整的主机地址、密钥、挑战验证和持久化流程。此前自动连接路径会直接启用输入而跳过配对，导致当次可用但关机后缺少回连密钥。
- 自动模式记住 NS2Pro 后，持续保留 BLE 监听，不再每隔一段时间为了搜索新的 DualSense 暂停 BLE。已配对 DualSense 的主动回连接收仍保留；添加新 DualSense 可以使用管理器的“配对”操作。
- 普通唤醒继续使用已有密钥；不同地址的陌生手柄不能通过配对广播替换已记住的手柄。
- 新增 `ns2 diagnostics`，显示固件版本、是否存在配对密钥、广播匹配计数、连接阶段和失败信息，不输出密钥内容。管理器模块的自检也包含这项诊断。

更新：在 Manager 的“固件更新”中检查更新，下载 `bl616-unified-0.2.4-preview.1.cbmodule`，再执行“通过 USB 更新 BL616”。不需要为此重装 Manager。旧固件尚未完成配对的手柄，更新后请先用手柄配对键或管理器“配对”完成一次配对，再测试“短按连接键关机 → 按普通按键唤醒”。

保留四种 USB 输出角色、按键映射、电量/去重报告率、音频/振动和现有签名 OTA。Boot2 和分区表不变。

验证：新增测试在修改前分别复现“物理配对广播未启动配对”和“已有 NS2 目标仍被 Classic 搜索中断”；修改后通过。覆盖已保存/未保存目标、同一手柄重新配对、陌生设备隔离、100 次回连重试、显式停止、计时回绕和最大计数诊断 JSON。完整主机回归、BL616 目标构建、签名 OTA 校验及 Manager 模块安装校验在发布前运行。

本次没有烧录用户正在测试的接收器，也没有完成实际关机/唤醒的硬件验收。以上测试证明相关代码路径已修正，不代表现场问题已确认全部解决。

ControllerBridge Manager 0.3.9-preview.1

修复 BL616 在 DualSense / DualSense Edge USB 模式下升级极慢的问题。旧固件可能在处理 OTA 数据前先返回已经读完的上一条回复，随后关闭管理回复通道；0.3.8 会持续读取原生 Sony 报告，逐包累积无效等待。新版在发现过期、空或不可用回复时，立即重发同一未确认数据包，重新打开回复通道；继续繁忙时采用有上限的退避，整个事务仍受 30 秒期限约束。

该修复兼容已有 BL616 固件，不需要先升级接收器才能获得改进。序号、操作和偏移匹配、重复包幂等处理、镜像签名、哈希、版本防回退及启动健康检查均保留。没有增加无确认的并行写入。

升级传输循环不再逐包返回 UI 线程，界面进度限制为每秒约五次，并显示已传输大小、平均速度及预计剩余时间；全部数据传输后仍须等待固件校验和启动确认。

验证：

- 使用现有 BL616 USB 实现和实际回复游标代码，在主机编译测试中复现 DualSense / Edge 回复通道被提前关闭，并确认重发同一数据包可恢复通道。
- 1,000 个 46 字节包的离线竞态回归：旧代码请求 1,210,000 ms 无效等待及 66,000 次读取；修复后该等待为 0、读取为 3,000 次，仍只接受 1,000 次唯一写入。这是离线复现结果，不是实机耗时或吞吐承诺。
- 核心回归涵盖及时/延迟/过期确认、丢失确认、取消及锁释放、签名和防回退检查；最终发布包执行离线界面回归。

保留 0.3.8 的 ESP32-S3 两级选择、Fluent 卡片主页、实时手柄图、源报告率、电量与映射功能。四平台固件模块与锁定清单保持逐字节一致，本次只更新管理器。

在 Manager 更新中启用“包含预发布版本”，或下载安装包/便携包。正在运行的旧管理器不会热替换；不要同时打开第二个管理器访问正在升级的接收器。

本次未中断用户正在进行的 OTA，也未对设备另行刷写或执行竞争性 HID 查询；实机升级速度和硬件兼容性仍需在新版上确认。安装器与便携版未做代码签名。

# ControllerBridge Manager 0.3.6-preview.1

本次为测试版本。旧版管理器打开“Manager 更新”，勾选“包含预发布版本”后检查更新。

## 管理器

- 保留卡片式主页与已有功能入口，调整为 WinUI / Fluent 的控件圆角和系统强调色。
- 首页新增有效输入率、电量。有效输入率使用接收器的源帧计数，重复发送的 USB 缓存帧不重复计数；按键静止但时间戳更新的源帧仍计入。USB 原始收包率、设置目标频率分别显示。旧固件不提供源帧标识时显示不可测，不把原始收包率作为去重结果。
- 只显示真实来源的电量。NS2Pro 目前未解析出电量时显示未知，不使用模拟 DualSense 输出中的占位 100%。
- 重绘 DS5、NS2Pro、Xbox 实时线稿，校正机身、触摸板、按键和握把比例；支持深浅主题、按键高亮、扳机深度、圆形范围内的摇杆位移，以及松开、断线和过期输入清空。
- 修复 BL616 按键映射命令兼容：按物理输入手柄保存配置，适用于该手柄的全部 USB 输出身份；保留 25 个映射槽位及 SF32 原有映射方式。
- 修复切换固件模块后迟到的空导航事件覆盖当前页面的问题。

## BL616 0.2.3-preview.1

- 针对 NS2Pro 按连接键关机后、按任意按键无法回连的情况，修复自动连接失败后遗留的 SDK 状态、扫描恢复和取消连接的重试处理。
- 接受已配对目标的无名称定向广播，避免在接收回调中同步停止扫描；连接超时后恢复扫描，失败不会丢失后续重试。
- 新增有效源帧计数、计时时间和真实来源的电量字段。
- 保留上一测试版的临时 XInput USB 身份 FFFE:CB16 和既有 OTA 验签机制。

管理器安装包包含该固件，同时提供独立 `.cbmodule`。安装管理器不会自动刷写接收器；请在“固件更新”中选择 BL616 0.2.3-preview.1 并执行 USB OTA。旧管理器也可以通过固件更新源获取独立模块。

## 验证与限制

- 管理器核心测试及离线原生界面回归：宽窄窗口、深浅主题、输入图形、导航、映射、更新控件、创建流程。
- BL616 主机回归：重复帧计数、静止新帧、映射与持久化、连续 100 次连接失败重试、扫描/取消失败恢复。
- 发布包校验包括文件哈希、模块完整性及签名 OTA 镜像验证。
- 未刷写真实设备，NS2Pro 关机后按键唤醒仍需实机验收。Windows 安装程序未进行 Authenticode 签名；BL616 OTA 使用既有发行密钥签名，两者不同。

首次安装可下载 Setup，便携版请解压到新目录运行。升级前关闭旧版管理器。
